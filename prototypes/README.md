# Prototypes

Standalone experiments that are **not** wired into the site. Open the HTML files
directly (they load three.js from a CDN) or serve the folder.

## accretion-flow-study.html

A self-contained three.js study of an alternative black-hole hero: the accretion
disk as one continuous ribbon — the front edge streams past the shadow and the
far half is gravitationally lensed into circular arcs over the top and under the
bottom, joining the front edge at the left/right shoulders. Cursor stirs the
particles only (no full-frame warp).

Parked for now — the live hero keeps the simpler particle disk in
`components/BlackHole.tsx`. Revisit this file to iterate on the lensed-ribbon
look before porting anything into the component.

Live version of this prototype: https://claude.ai/code/artifact/d27b2377-53a4-4649-85d2-ecc728222cb8
